## Features
- 14-key linear macro pad layout
- Transparent keycaps for enhanced RGB lighting effects
- Colorful LED lighting for a "party" style visual appearance
- Keys can be assigned to function keys (F-keys) or other macros
- LED override indicators for Caps Lock and Num Lock
